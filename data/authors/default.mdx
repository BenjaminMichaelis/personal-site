Benjamin Michaelis is a pragmatic, product-minded software engineer at [IntelliTect](https://intellitect.com/) who builds reliable web and cloud systems and developer tools that help teams ship faster. Benjamin designs full-stack web applications, cross-platform .NET solutions, and cloud architectures that solve business problems — from offline-capable clients to serverless pipelines and enterprise integrations.

He holds a B.S. in Software Engineering from Washington State University and maintains multiple Microsoft and GitHub certifications, including Azure Solutions Architect Expert, Azure Administrator Associate, and GitHub Actions. At IntelliTect he’s helped build multiple product offerings across higher education, utilities, financial services, and startups — including [StormingTheCastle.com](https://stormingcastle.com/) — delivering large web apps, automated CI/CD, asynchronous serverless workloads, and Microsoft Graph integrations.

Benjamin is the primary maintainer of [EssentialCSharp.com](https://essentialcsharp.com/) and co-author of the book Essential C#. He drives the site’s tooling, content, and roadmap, and implemented AI-powered chat features using embedding-based vector database lookups to deliver context-aware, searchable code guidance. An active open-source contributor, he publishes NuGet packages, GitHub Actions, and developer utilities (see his [GitHub](https://github.com/BenjaminMichaelis) and [NuGet](https://www.nuget.org/profiles/BAM423) profiles).

He teaches the .NET programming course at Eastern Washington University, guest-lectures across the PNW, and mentors new developers. Outside of code he enjoys outdoor adventures, photography, and staying active with friends and family.
